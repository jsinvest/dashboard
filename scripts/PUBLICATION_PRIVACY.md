# 공개 자료 개인정보 검사

자료 생성·원천 검증이 끝나고 Git 스테이징하기 전에 실행한다.

```text
python scripts/publication_privacy.py --apply
python scripts/audit_dashboard_freshness.py
python scripts/publication_privacy.py --check
```

공개 복제본의 로컬 사용자명·절대 경로는 충돌 없는 원천 파일 별칭으로 바꾼다. 원본 수집 폴더·자료·소스 검증값은 수정하지 않는다. ZIP의 `PUBLIC_PRIVACY_MANIFEST.json`에는 정정 전후 파일 해시를 기록한다. 기존 생성기 검증은 정정 전 원천 자료에 대한 것이며, 공개 복제본의 바이트 일치 검증과 구분한다.

공개 파일을 참조하는 다운로드 메타데이터의 ZIP 크기·해시와 공개 검증 래퍼의 해시는 최종 공개 바이트를 기준으로 다시 계산한다. 데이터 날짜·숫자·추천·선물 만기는 변경하지 않는다. 파일·JSON 키의 충돌이 발생하면 게시하지 않는다.

실행 코드의 개인 절대 경로는 `Path.home()` 또는 운영체제 홈 디렉터리 API로 수정한다. 검사기는 실행 코드를 임의로 가린 경로로 바꿔 실행을 깨뜨리지 않으며, 절대 경로가 남으면 실패한다.

커밋 작성자에는 GitHub 비공개 메일 별칭을 사용한다. 이 검사는 이전 Git 기록이나 외부 서버의 목록·Drive 공유 권한을 삭제하지 않는다. 화면에서 링크를 숨기는 것은 원천 서버의 링크 삭제 또는 공유 해제를 대신하지 않는다.

로컬 저장소의 pre-push 검사기는 업로드할 커밋의 실제 파일·ZIP과 새 커밋의 작성자/커미터 메일을 검사한다. 다른 checkout의 미스테이징 변경은 읽거나 수정하지 않는다. 위반 시 업로드를 중단하므로 원천 검증 후 공개 복제본 정리를 먼저 실행한다. GitHub 웹 편집이나 다른 컴퓨터에는 로컬 훅이 적용되지 않는다.
