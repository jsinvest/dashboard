# 종목 가격의 거래소·마감 기준 확인

가격 불일치는 우선 조사할 항목이며, 서로 다른 마감 기준의 값이 같아야 한다는 뜻은 아니다. 이 절차는 기존의 `base_pric == 전일 일봉 cur_prc` 무조건 일치 검사보다 우선한다. 원본 가격이나 과거 검증 결과는 덮어쓰지 않는다.

## 비교할 기준

- 종목코드, 실제 거래일, 거래소(KRX/NXT/통합), 정규장·애프터마켓 포함 범위, 단위와 수정주가·권리행사, 가격 필드의 뜻, 조회시각을 함께 확인한다.
- KRX 기본 종목코드도 애프터마켓 가격을 포함할 수 있다. `_NX`/`_AL` 코드를 바꾸거나 조회시각만 늦추면 정규장 종가가 된다고 가정하지 않는다.
- 같은 종목·같은 날짜의 KRX 정규장 마지막 봉이 기준가와 맞고, 애프터마켓 마지막 봉이 전일 일봉 가격과 맞는지를 각각 대조한다. 두 개가 확인되면 `SESSION_DIFFERENCE_CONFIRMED`로 기록한다. 모든 불일치를 정상 차이로 바꾸지 않는다.
- 원천 날짜·코드·시간대·요청 조건·해시, 중복·결측·비정상 OHLC 검사를 유지한다. 같은 시장·같은 세션끼리도 값이 다르거나 끝점 근거가 없으면 `UNRESOLVED`다. 권리행사·수정주가 차이를 세션 차이로 통과시키지 않는다.

2026-11-18 동국제약의 정규장 종가는 24,400원, 애프터마켓 마지막 5분봉 종가는 24,600원이었다. CJ ENM은 각각 42,150원과 47,000원이었다. 두 종목 모두 기본정보 기준가와 일봉 최종가격이 서로 다른 세션의 실제 가격에 맞았다. 이 두 표본을 다른 종목의 검증으로 대신하지 않는다.

## 검사 도구

`stock_price_session.py`는 저장된 기본정보·일봉과 별도로 확보한 KRX 5분봉을 비교한다. 수집·주문·메시지·게시를 실행하지 않는다. 원본 파일과 생성기 검토 근거의 경로·SHA256을 갖는 별도 wrapper를 사용하며, 원본 응답에 없던 요청 조건을 추측하여 쓰지 않는다.

```powershell
python scripts/stock_price_session.py --chart-raw <chart-wrapper.json> --intraday-raw <krx-5m-response.json> --trade-date YYYYMMDD --previous-date YYYYMMDD --regular-close HHMMSS --output <new-validation.json>
```

정규장 마감시각은 해당 날짜의 공식 일정으로 확인한다. 예를 들어 2026-11-18은 15:30, 수능일인 2026-11-19는 16:30이다. 다른 날짜의 특별시장 시간을 재사용하지 않는다. 도구의 종료코드 0은 이 가격 비교가 설명됐다는 뜻이며, 전 시계열·다른 지표·추천종목·대시보드 전체의 승인이나 거래소 독립 검증을 뜻하지 않는다. 종료코드 2는 근거 부족 또는 미해결이다.

여러 종목은 `reconcile_stock_price_sessions.py --cases <cases.json> --output <batch-validation.json>`으로 한 번에 검사한다. 목록의 각 항목은 `code`, `chart_raw`, `intraday_raw`, `trade_date`, `previous_date`, `regular_close`를 갖는다. 결과에는 후속 선정 검사를 계속할 수 있는 종목과 미해결 종목을 따로 기록한다. 일부 미해결로 종료코드 2가 나와도 다른 종목의 정상 근거를 폐기하거나 독립 시장자료 게시를 차단하지 않는다. 이 도구도 추천 선정 완료를 선언하지 않는다.

## 진행봉과 완료봉

15시 1차 분석은 장중 잠정 분석이다. 당일 봉을 확정 일봉으로 표현하지 않는다. 21시에도 시각과 날짜만으로 당일 일봉 반영 완료를 선언하지 않는다. 키움 일반 차트 안내는 일봉을 20시 기준으로 생성하여 익일부터 반영한다고 설명한다. REST 응답도 무조건 같다고 가정하지 말고 실제 해당 날짜의 마감 봉·거래량·원천 상태를 확인한다.

과거 완료봉의 지표와 당일 진행 중 확인값은 분리한다. 확정 일봉이 필요한 선정 조건에 미완료 봉을 쓰지 않는다. 정규장 기준 분석과 애프터마켓을 포함한 분석은 기간 전체에 같은 정의를 적용한다. 과거 20시 일봉에 당일 정규장 값 하나만 끼워 넣어 완성된 시계열로 사용하지 않는다.

## 게시에 미치는 영향

설명된 세션 차이는 가격 오류나 전체 게시 차단으로 취급하지 않는다. 비교에서 해소되지 않은 종목만 선정에서 제외하고, 그에 의존하지 않는 검증된 시장분석·선물옵션·다른 자료의 게시를 계속한다. 다른 필수 검증은 유지한다.

이 검사 통과만으로 후보를 최종추천으로 승격하지 않는다. 차트·누적수급·뉴스·추격위험 등 기존 선정 조건을 다시 확인한다. 모든 후보가 미검증이면 `recommendation_selection_complete=false`와 원인을 남긴다. 추천 0개를 정상 선정 완료로 위장하지 않는다. 해당 부분 분석 게시와 전체 갱신 완료는 구분한다.

원천 요청·조회시각·거래일·세션·가격·해시·판정·제외 종목·실제 복구 결과를 새 검증 파일에 기록한다. 이전 실패 기록은 증거로 보존한다. 같은 검사를 반복하는 대신 필요한 분봉이나 날짜·시장 대조만 수행한다.

## 예약 적용

15시 1차, 21시 최종, 21/23시 AI, 22시 전체 점검에서 이 절차를 사용한다. AI 예약은 기존 외부 시세 조회 금지를 유지하며, 로컬 근거가 부족하면 필요한 검증과 경로를 기록해 담당 예약과 점검기가 읽도록 한다. 다른 채팅에 메시지를 보내지 않는다. 기존 예약 시각, 22시 현금 담당, 공유 파일 순차 편집, 중복 방지와 공개 PC·모바일 검증을 유지한다. 새 알림·자동주문·전체 배치 재실행 권한을 추가하지 않는다.
